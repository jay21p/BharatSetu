# 🇮🇳 BharatSetu

> **A bridge between people and technology.**

**BharatSetu** is an Android application developed to provide a simple and accessible mobile experience. The project is built using **Java, XML, Android Studio, and Gradle**.

---

## 📱 Requirements

Before running BharatSetu, make sure you have:

* **Android Studio**
* **Android device**
* **USB cable**
* **Bitchat installed on the Android device**

> ⚠️ **Important:** Bitchat must be installed on the device for BharatSetu to function correctly.

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/jay21p/BharatSetu.git
```

### 2. Open the Project

1. Launch **Android Studio**.
2. Select **File → Open**.
3. Select the cloned `BharatSetu` folder.
4. Wait for **Gradle Sync** to complete.

### 3. Prepare Your Device

Make sure **Bitchat is installed** on your Android phone.

---

## 📲 Run on Android Mobile

1. Open **Settings → Developer Options** on your phone.
2. Enable **USB Debugging**.
3. Connect your phone to your computer using a USB cable.
4. Allow the USB debugging permission when prompted.
5. Open the BharatSetu project in Android Studio.
6. Select your connected phone from the **device selector**.
7. Click **Run ▶**.
8. Android Studio will build and install BharatSetu on your phone.
